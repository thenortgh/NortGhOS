## Getting Started

### Prerequisites
To build and run NortGhOS, you will need the following tools installed:

* **Emulators & Debuggers:**
  * `QEMU` (Required for running the OS)
  * `Bochs` (Optional, recommended for debugging)
* **Development Environments:**
  * `MSYS2` (For Windows users)
  * `WSL` (Windows Subsystem for Linux)
* **Compilers & Assemblers:**
  * `NASM` (Netwide Assembler)
  * `GCC` (GNU Compiler Collection)
* **Scripting:**
  * `Python`

> 💡 *Note: For a complete list of required dependencies, please check the `tools/` folder in this repository.*

### Building and Running the Project
You can easily build and launch the operating system using the provided scripts. Run the following commands in your terminal:

```bash
# Build the operating system
./build.sh

# Run the operating system in the emulator
./run.sh
```
